<h2 style="color: #333;">✨ About This Project</h2>
<p>
  <strong>Logis</strong> is a clean and professional website themed around logistics, shipping, and transport services.
  Originally intended as a Bootstrap-based template, this version is a fully manual rebuild with no frameworks, no shortcuts — just pure HTML5 and CSS3. It was done for fun, as a challenge, and for frontend muscle memory.
</p>

<h2 style="color: #333;">🎯 Features & Layout</h2>
<ul>
  <li>Hero section with CTA & background image</li>
  <li>Service highlights, about section, and testimonials</li>
  <li>Partner logos and pricing blocks</li>
  <li>Responsive design!</li>
  <li>Footer & contact panel styled for real-world use</li>
</ul>

<h2 style="color: #333;">🧪 Technologies</h2>
<ul>
  <li>🧱 <strong>HTML5</strong> – All sections structured semantically</li>
  <li>🎨 <strong>CSS3</strong> – Custom styles, transitions, responsive grid/flex layouts</li>
</ul>
